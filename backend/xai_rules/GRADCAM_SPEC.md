# AgriShield – Grad-CAM Explainable AI Module

## 1. Introduction

Grad-CAM (Gradient-weighted Class Activation Mapping) is an Explainable Artificial Intelligence (XAI) technique used to visualize the image regions that influence a convolutional neural network's prediction.

In AgriShield, Grad-CAM provides visual explanations for crop disease predictions generated by the trained MobileNetV2 model.

## 2. Objectives

- Improve the interpretability of crop disease predictions.
- Highlight important regions of leaf images.
- Provide visual explanations alongside disease predictions.
- Maintain consistency with the original classification model.

## 4. Implementation Workflow

1. Accept the leaf image path.
2. Resize the image to 224 × 224 pixels.
3. Apply MobileNetV2 preprocessing.
4. Load the trained classification model.
5. Extract the final convolutional feature maps.
6. Calculate gradients for the predicted class.
7. Calculate channel importance weights.
8. Generate and normalize the activation heatmap.
9. Overlay the heatmap on the original leaf image.
10. Display the predicted class and confidence.

## 5. Mathematical Formulation

The importance weight of feature map k is calculated by averaging the gradients of the predicted class score across its spatial dimensions.

αₖᶜ = (1/Z) Σᵢ Σⱼ (∂yᶜ / ∂Aᵢⱼᵏ)

The Grad-CAM heatmap is calculated as:

Lᶜ = ReLU(Σₖ αₖᶜ Aᵏ)

Where:

- yᶜ: Predicted class score.
- Aᵏ: Convolutional feature map.
- αₖᶜ: Importance weight of feature map k.
- Z: Number of spatial locations.
- ReLU: Rectified Linear Unit activation.
